# One Million Coins Build Planner

Unofficial fan tool for planning and sharing One Million Coins proficiency builds (ruleset vault-1.2).

Pick skills, set their purchase order, and see the coins needed at each step. The URL updates as you build, so it is always a share link that carries the build, name, author, target time and notes.

Everything lives in `index.html`. Links store positions in the skill list, so only add new skills to the end of that list.

Not affiliated with the game's developers. Icons are original and no game art is included.
